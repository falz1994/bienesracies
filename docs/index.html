Metodología y oportunidades

Cómo se construyó el análisis y por dónde puede crecer.

HERRAMIENTAS

Pipeline construido con OpenCode usando GLM 5.3 Flash (Z.ai) para el análisis de datos y el diseño de los slides.

FUENTES DE DATOS

KW Nicaragua: API GraphQL pública, con coordenadas nativas. QuieroCasa y Momotombo: HTML sin API ni coordenadas — geocodificadas por nombre de zona con OpenStreetMap/Nominatim.

CONSOLIDACIÓN

Deduplicación entre portales (±110 m y precio similar), filtro a Managua + Ciudad Sandino + Ticuantepe (Nindirí excluido) y ranking por promedio de venta.

OPORTUNIDADES FUTURAS

Encuentra24, Facebook Marketplace y clasificados entre particulares; precio por m²; históricos y propiedades vendidas; alquileres y más segmentos.
